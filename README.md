# Failure-Aware Software Development

A research program of the [Duality Lab](https://davisjam.github.io/), led by
James C. Davis at Purdue University.

Learning from software failures, and converting failure knowledge into development structures and decisions. FA-SDLC is the named current framework.

This repository hosts the program's project site, published at
<https://davisjam.github.io/failure-aware-software-development/>.

The site is under construction.
